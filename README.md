# 코딩 테스트 정석 스터디

> 처음 보는 문제를, 내가 아는 문제로 바꾸는 연습

문제 수를 채우기보다 반복되는 풀이 패턴을 바둑의 정석처럼 체화하는 프로젝트입니다. 목표는 모든 고난도 문제를 푸는 것이 아니라, 일반적인 개발자 채용 코딩 테스트에서 합격에 필요한 점수를 안정적으로 얻는 것입니다.

## 12주 후 목표

- 문제를 읽고 10분 안에 후보 알고리즘을 압축한다.
- 입력 크기로 허용 시간 복잡도를 계산한다.
- 빈출 알고리즘은 검색 없이 구현한다.
- 120분 모의고사에서 중간 난이도 2~3문제를 안정적으로 푼니다.
- 풀 문제와 보류할 문제를 빠르게 구분한다.
- 실패 원인을 발상·구현·검증·전략으로 분류한다.

## 학습 원칙

1. 코드를 쓰기 전에 문제를 분석한다.
2. 정석은 `적용 단서 → 핵심 상태 → 불변식 → 최소 코드 → 실수`로 정리한다.
3. 풀이를 본 문제는 48시간 이내와 7일 후에 AI 없이 다시 구현한다.
4. 답을 맞힌 것뿐 아니라 문제 선택과 시간 사용도 회고한다.
5. 고난도 선택 문제는 완전한 습득보다 유형 인식과 포기 판단을 우선한다.

## 프로젝트 구조

```text
algorithm/       재사용할 알고리즘 정석 스니펫
solve/           사이트·주제별 문제 풀이
study/           스터디 운영 방식, 커리큘럼, 기록 양식
book/            교재를 따라 풀은 문제
```

## 완료 기준

알고리즘은 설명을 읽었을 때가 아니라, 다음 조건을 모두 만족했을 때 완료로 표시합니다.

- 적용 단서와 불변식을 자신의 말로 설명했다.
- 검색 없이 기본 스니펫을 작성했다.
- 기본 문제와 변형 문제를 풀었다.
- 48시간 재구현에 성공했다.
- 7일 재구현에 성공했다.
