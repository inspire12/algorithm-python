# 유형별 스니펫 지도

스니펫의 목표는 긴 코드를 통째로 암기하는 것이 아닙니다. **언제 쓰는지, 어떤 상태가 필요한지, 반복문이 무엇을 보장하는지**를 함께 기억하는 것입니다.

## 핵심 유형 지도

|---|---|---|---|---|
| 해시 | 존재·빈도·그룹 조회 | `seen`, `count`, `groups` | 조회 후 갱신 | 중복 개수 무시 |
| 정렬 | 순서가 선택을 단순화 | 정렬 기준 튜플 | `key=lambda x: (...)` | 복합 기준 방향 |
| 스택 | 최근 미해결 항목 처리 | `stack` | 넣기 전 조건에 따라 꺼내기 | 빈 스택 접근 |
| [경계 확정형 단조 스택](course/special-problem-types.md#머리-풀기-경계-확정형-단조-스택) | 각 원소의 첫 낮은 양쪽 경계 | 미확정 인덱스 스택 | 현재가 낮으면 pop 후 포함 경계 계산 | 경계 포함 여부 혼합 |

## 스니펫을 정확히 안다는 기준

각 유형은 아래 다섯 단계로 평가합니다.

| 단계 | 할 수 있는 일 |
|---:|---|
| 0 | 이름만 들어봤다. |
| 1 | 완성 코드를 읽고 설명할 수 있다. |
| 2 | 적용 조건과 핵심 상태를 말할 수 있다. |
| 3 | 검색 없이 최소 스니펫을 작성하고 기본 테스트를 통과한다. |
| 4 | 변형 문제에서 상태·종료 조건을 바꿔 적용한다. |
| 5 | 시간 제한 안에 유형 선택, 구현, 반례 검증까지 완료한다. |

스터디의 완료 기준은 기본 유형은 4단계, 코딩 테스트 통과 목표 유형은 5단계입니다.

## 부분집합의 개수와 복사 비용

- 문제: [Subsets — LeetCode 78](https://leetcode.com/problems/subsets/)
- 기록일: 2026-10-14
- 인식 단서: 서로 다른 N개 원소의 모든 부분집합을 반환한다. 순서는 무관하고 빈 부분집합도 포함한다.
- 적용 조건: 각 원소는 포함하거나 포함하지 않는다. 입력에 중복값이 있으면 별도의 중복 제거가 필요하다.
- 상태와 연산: 현재 경로와 다음 선택 시작 인덱스. 선택 → 다음 인덱스로 재귀 → 선택 취소. 결과에는 경로를 복사하여 저장한다.
- 최소 흐름과 불변식: 빈 집합을 포함하고, 경로의 선택 인덱스는 엄격히 증가한다. 재귀 호출이 끝나면 공유 경로는 호출 전 상태로 복구된다.

| 항목 | 기억할 값 | 근거 |
|---|---|---|
| 부분집합 수 | 2^N | 원소마다 포함/미포함 두 선택 |
| 비어 있지 않은 부분집합 수 | 2^N - 1 | 빈 집합 한 개만 제외 |
| 결과에 저장된 원소 수 합 (N >= 1) | N × 2^(N-1) | 각 원소는 전체 부분집합의 절반에 등장 |
| 전체 시간 | O(N × 2^N) | 모든 결과를 복사하는 비용 포함 |
| 출력 포함 공간 | O(N × 2^N) | 모든 부분집합 저장 |
| 출력 제외 보조 공간 | O(N) | 현재 경로와 재귀 스택 |

예: N=3이면 부분집합 8개, 저장된 원소 수의 합은 3×4=12개다. N=0이면 빈 집합 하나이며 저장된 원소 수는 0개다.

암기 문장: **부분집합은 2^N개, 결과 복사까지 포함하면 N×2^N, 작업 경로만 보면 N.**

주의: N^2과 2^N을 구분한다. 반복문 개수보다 후보 수와 후보당 복사 비용으로 계산한다.

## 딕셔너리 값을 기준으로 키 정렬하기

- 문제: [Top K Frequent Elements — LeetCode 347](https://leetcode.com/problems/top-k-frequent-elements/)
- 기록일: 2026-11-12
- 인식 단서: 숫자 자체가 아니라 등장 횟수 순으로 원소를 선택한다.
- 적용 조건: 빈도 집계가 완료되어 있고, 전체 정렬 비용이 허용된다.
- 상태와 연산: `freq`의 키는 원소, 값은 빈도다. `sorted`는 새 리스트를 반환한다.

```python
sorted_numbers = sorted(freq, key=freq.get, reverse=True)
answer = sorted_numbers[:k]
```

- `key=freq.get`: 각 키의 값을 비교 기준으로 사용한다. `reverse=True`: 내림차순.
- 불변식: 정렬 결과의 인접 원소는 앞 원소의 빈도가 뒤 원소보다 크거나 같다.
- `sorted(freq)`는 키 자체를 정렬하며 원본 딕셔너리를 바꾸지 않는다. `[k]`는 원소 하나, `[:k]`는 앞 K개다.
- N개 입력, U개 고유 원소: 평균 집계 O(N), 정렬 O(U log U), 전체 O(N + U log U), 보조 공간 O(U).
- 이 문제의 O(N log N)보다 빠른 후속 요구는 아직 해결하지 않았다. 빈도별 버킷 최적화는 추후 학습한다.
