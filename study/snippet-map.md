# 유형별 스니펫 지도

스니펫의 목표는 긴 코드를 통째로 암기하는 것이 아닙니다. **언제 쓰는지, 어떤 상태가 필요한지, 반복문이 무엇을 보장하는지**를 함께 기억하는 것입니다.

## 핵심 유형 지도

| 유형 | 적용 조건 | 최소 상태 | 반드시 기억할 뼈대 | 대표 실수 |
|---|---|---|---|---|
| 해시 | 존재·빈도·그룹 조회 | `seen`, `count`, `groups` | 조회 후 갱신 | 중복 개수 무시 |
| 정렬 | 순서가 선택을 단순화 | 정렬 기준 튜플 | `key=lambda x: (...)` | 복합 기준 방향 |
| 스택 | 최근 미해결 항목 처리 | `stack` | 넣기 전 조건에 따라 꺼내기 | 빈 스택 접근 |
| [경계 확정형 단조 스택](course/special-problem-types.md#머리-풀기-경계-확정형-단조-스택) | 각 원소의 첫 낮은 양쪽 경계 | 미확정 인덱스 스택 | 현재가 낮으면 pop 후 포함 경계 계산 | 경계 포함 여부 혼합 |
| 큐/BFS | 가중치 없는 최단 거리 | `queue`, `dist` | 방문 처리 후 큐 삽입 | 꺼낼 때 방문 처리 |
| DFS | 연결 탐색·선택과 복구 | `visited` 또는 경로 | 선택 → 재귀 → 복구 | 복구 누락 |
| 힙 | 최소·최대 후보 반복 선택 | `heap` | push/pop, 오래된 값 폐기 | 최대 힙 부호 |
| 누적합 | 정적 구간 합 반복 | `prefix` | `prefix[r] - prefix[l]` | 경계 정의 혼합 |
| 투 포인터 | 정렬/연속 구간의 경계 이동 | `left`, `right` | 조건에 따라 한쪽 이동 | 이동 조건 불명확 |
| 슬라이딩 윈도우 | 연속 구간 상태 증분 갱신 | 창의 합·빈도 | 오른쪽 추가 → 왼쪽 제거 | 제거 상태 미갱신 |
| 이분 탐색 | 정렬 또는 단조 판정 | `lo`, `hi`, `mid` | 경계 불변식 유지 | 열린/닫힌 구간 혼합 |
| [파티션 이분 탐색](course/concepts/binary-search-partition.md) | 두 정렬 배열의 전체 순위 경계 | 두 파티션 개수와 네 경계값 | 왼쪽 총개수 고정 → 교차 조건 검사 | 두 배열의 중앙을 독립 탐색 |
| 다익스트라 | 음수 없는 가중 최단 거리 | `dist`, `heap` | 완화와 오래된 항목 폐기 | BFS와 조건 혼동 |
| 위상 정렬 | 선행 관계·DAG | `indegree`, `queue` | 진입차수 0 처리 | 사이클 확인 누락 |
| Union-Find | 집합 연결·합치기 | `parent`, `rank/size` | find 압축, union | 루트 아닌 값 연결 |
| DP | 같은 상태의 답 반복 사용 | `dp[state]` | 정의 → 점화식 → 초기값 → 순서 | 상태 정의 불명확 |
| 백트래킹 | 작은 입력의 모든 선택 | 경로·사용 여부 | 선택 → 탐색 → 복구 | 가지치기·복구 누락 |

## 스니펫을 정확히 안다는 기준

각 유형은 아래 다섯 단계로 평가합니다.

| 단계 | 할 수 있는 일 |
|---:|---|
| 0 | 이름만 들어봤다. |
| 1 | 완성 코드를 읽고 설명할 수 있다. |
| 2 | 적용 조건과 핵심 상태를 말할 수 있다. |
| 3 | 검색 없이 최소 스니펫을 작성하고 기본 테스트를 통과한다. |
| 4 | 변형 문제에서 상태·종료 조건을 바꿔 적용한다. |
| 5 | 시간 제한 안에 유형 선택, 구현, 반례 검증까지 완료한다. |

스터디의 완료 기준은 기본 유형은 4단계, 코딩 테스트 통과 목표 유형은 5단계입니다.

## 스니펫 검증 항목

새 스니펫을 `algorithm/`에 추가할 때 다음을 함께 둡니다.

- 적용 조건과 사용하면 안 되는 조건
- 핵심 상태와 불변식
- 시간·공간 복잡도
- 최소 입력, 일반 입력, 답 없음, 극단 입력 테스트
- 48시간과 7일 후 빈 파일에서 재구현한 기록

스니펫에 문제별 변수명이나 입출력 코드를 섞지 않습니다. 문제 풀이는 `solve/`에, 재사용 가능한 뼈대와 테스트는 `algorithm/`에 둡니다.
