# 머리 풀기 문제 목록

본 학습이나 복습 전에 10~15분 동안 알고리즘 상태와 경계 감각을 깨우는 문제를 관리합니다. 문제별 이해도와 다음 일정은 `study/problem-registry.json`이 유일한 기준이며, 이 문서는 문제 선택 목적과 회상 포인트만 기록합니다.

## 등록 기준

다음 조건 중 두 가지 이상을 만족하면 머리 풀기 후보로 검토합니다.

- 코드는 짧지만 핵심 불변식이나 경계 계산이 기술적이다.
- 한 반례로 비교 방향이나 갱신 순서를 빠르게 점검할 수 있다.
- 스택, 덱, 포인터, 이분 탐색 등 기본 템플릿을 빈 파일에서 재현하기 좋다.
- 10~15분 안에 구현과 구두 설명까지 완료할 수 있다.
- 자주 잊는 포함·제외 경계나 상환 복잡도를 확인할 수 있다.

정답 코드를 기억하는 문제는 제외하고, 불변식과 후보 제거 근거를 다시 도출할 수 있는 문제만 유지합니다.

## 문제별 카드

### Largest Rectangle in Histogram

- 상세 유형: [경계 확정형 단조 스택](special-problem-types.md#머리-풀기-경계-확정형-단조-스택)
- 시작 질문: 막대 하나를 최소 높이로 고정하면 최대 너비를 막는 두 경계는 무엇인가?
- 최소 불변식: 스택에는 오른쪽의 더 낮은 경계를 아직 만나지 않은 인덱스가 높이 비감소 순서로 있다.
- 포함 왼쪽: `pop` 후 스택 위의 다음 칸, 스택이 비면 `0`
- 포함 오른쪽: 현재 낮은 막대의 이전 칸
- 종료 처리: 높이 `0` 센티널
- 복잡도 근거: 각 인덱스는 한 번 `push`되고 최대 한 번 `pop`된다.

확인 반례:

```text
[2]
[1, 2, 3]
[3, 2, 1]
[2, 2, 2]
[2, 1, 2]
[2, 1, 5, 6, 2, 3]
```

## 사용 방법

1. 유형 이름을 보지 않고 시작 질문에 답한다.
2. 기준 풀이와 반복 병목을 2분 안에 말한다.
3. 최소 불변식을 작성한 뒤 구현한다.
4. 반례 하나를 손으로 추적한다.
5. 시간과 공간 복잡도를 총 연산 횟수로 설명한다.
6. 실패한 경우에만 해당 문제 레코드와 오답노트를 갱신한다.
