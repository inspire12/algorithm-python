# 알고리즘 강의 제작 공간

이 디렉터리는 개인 학습 상태와 분리된 강의 원고를 관리합니다.

- 개인별 진행 상태와 다음 행동: `study/problem-registry.json`
- 유형을 빠르게 찾는 요약 지도: `study/snippet-map.md`
- 학습자에게 전달할 강의 콘텐츠: `study/course/`

## 대상 학습자

Python 문법을 알고 있지만 알고리즘 풀이를 체계적으로 도출하는 데 익숙하지 않은 학습자를 기본 대상으로 합니다. 최종 목표는 코딩 테스트 정답뿐 아니라 라이브 코딩과 기술 면접에서 선택 근거, 불변식, 정확성, 복잡도를 설명하는 것입니다.

## 강의 원칙

각 유형은 다음 흐름으로 설명합니다.

1. 문제 계약
2. 정답 후보와 기준 풀이
3. 반복되는 병목
4. 한 가지 최적화
5. 필요한 상태와 연산
6. 반복 불변식
7. 정확성 증명
8. 시간·공간 복잡도
9. 반례와 흔한 실수
10. 최소 템플릿
11. 단계별 연습

유형 이름이나 완성 코드를 먼저 제시하지 않습니다. 기준 풀이에서 어떤 반복을 제거해야 하는지 확인한 뒤 유형과 템플릿을 연결합니다.

## 디렉터리

- `concepts/`: 유형별 개념과 재사용 가능한 최소 템플릿
- `problems/`: 대표 문제의 도출 과정과 해설
- `exercises/`: 단계별 문제, 힌트, 확인 질문
- `instructor-notes/`: 실제 오답, 반례, 설명 시 주의점
- `special-problem-types.md`: 여러 조건이 함께 나타날 때 쓰는 특수 유형 카드
- `learned-types-summary.md`: 레지스트리 기준으로 지금까지 다룬 유형과 보완점 요약
- `warm-up-problems.md`: 본 학습 전 10~15분 동안 푸는 머리 풀기 문제 목록
- `lesson-template.md`: 모든 강의 원고가 따르는 형식

## 작성 완료 기준

강의 한 편은 다음 조건을 만족해야 합니다.

- 적용 조건과 적용하면 안 되는 조건이 모두 있다.
- 자료구조에 저장하는 키와 값, 필요한 연산을 명시한다.
- 포인터 이동이나 후보 제거를 부등식 또는 불변식으로 설명한다.
- 기준 풀이와 개선 풀이의 복잡도를 비교한다.
- 최소 반례, 경계 입력, 일반 입력을 포함한다.
- 정답 코드 없이도 구현 가능한 상태 정의가 있다.
