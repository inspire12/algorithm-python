# 알고리즘 강의 커리큘럼

## 1부: 문제를 코드로 번역하기

1. 문제 계약과 반환 범위
2. 정답 후보와 기준 풀이
3. 병목을 연산 횟수로 표현하기
4. 상태, 갱신 시점, 불변식
5. 반례로 후보 제거를 검증하기

## 2부: 조회와 순서

1. 해시: 반복 탐색을 평균 `O(1)` 조회로 바꾸기
   - 대표 문제: Two Sum
   - 핵심 판단: 조회 후 삽입과 동일 인덱스 재사용 방지
2. 정렬: 순서가 선택을 단순하게 만드는 조건
3. 누적합: 반복되는 구간 합 제거

## 3부: 경계를 움직이는 문제

1. 읽기·쓰기 포인터
   - 대표 문제: Remove Duplicates from Sorted Array
2. 양끝 투 포인터
   - 대표 문제: Two Sum II, Container With Most Water
3. 슬라이딩 윈도우
   - 고정 길이와 가변 길이의 상태 차이
4. 양쪽 경계의 확정
   - 대표 문제: Trapping Rain Water
   - 비교: 구간 확정 방식과 위치 확정 방식

## 4부: 미해결 후보를 유지하는 자료구조

1. 스택과 최근 미해결 항목
2. 단조 스택
   - 대표 문제: Daily Temperatures, Largest Rectangle in Histogram
   - 머리 풀기: [경계 확정형 단조 스택](special-problem-types.md#머리-풀기-경계-확정형-단조-스택)
3. 단조 큐
   - 대표 문제: Sliding Window Maximum
   - 핵심 판단: 앞의 만료 제거와 뒤의 지배 후보 제거
4. 힙과 반복 최솟값·최댓값 선택

## 5부: 단조성을 이용한 탐색

1. 닫힌 구간 이분 탐색
2. lower bound와 upper bound
3. 답의 범위를 탐색하는 이분 탐색
4. 두 정렬 배열의 파티션 이분 탐색
   - 대표 문제: Median of Two Sorted Arrays
   - 핵심 판단: 파티션 개수를 후보로 정의하고 교차 경계를 검사
   - 유형 카드: [특수 문제 유형](special-problem-types.md#두-정렬-배열의-파티션-이분-탐색)

## 6부: 그래프 탐색과 연결

1. DFS와 BFS
2. 위상 정렬
3. 다익스트라
4. Union-Find

## 7부: 선택과 상태 재사용

1. 완전탐색과 백트래킹
2. 그리디와 교환 논증
3. DP 상태 정의
4. 점화식, 초기값, 계산 순서

## 8부: 면접형 종합 훈련

1. 풀이 전 4문장 고정
2. 코드 없이 정확성 설명
3. 실패한 접근과 병목 설명
4. 제한 시간 내 구현과 반례 검증

각 강의는 `개념 도출 → 대표 문제 → 변형 연습 → 무참조 재구현 → 구두 설명` 순서로 진행합니다.
